# SSH Proxy: Hybrid Direct & Tor Tunnel

**SSH Proxy** — это продвинутое и легковесное приложение для Windows, которое превращает ваш SSH-сервер в мощный SOCKS5 прокси-шлюз. Оно позволяет работать как напрямую через IP сервера, так и через сеть Tor с возможностью выбора страны выхода прямо из системного трея.

## 🌟 Основные возможности

- 🌍 **Multi-Country Tor Exit Nodes** — Выбирайте из более чем 20 стран (US, DE, FR, JP, SG и др.). Трафик пойдет по цепочке: `PC -> SSH Tunnel -> Remote Tor -> World`.
- 🚀 **Hybrid Modes** — Мгновенное переключение между "Direct" (чистый SSH) и "Tor" (анонимность) режимами.
- 🛠️ **Zero-Config Server Side** — Приложение само проверит наличие Tor на сервере, установит его (Debian/Ubuntu) и настроит изолированный инстанс в домашней папке пользователя, не затрагивая системные настройки сервера.
- 🔐 **Smart Key Management** — Автоматическая генерация RSA-ключей и их безопасная доставка на сервер (требуется пароль только при первом подключении).
- 🖥️ **Native Windows Integration** — Легкий GUI на чистом WinAPI, работа в трее и опция автоматического запуска вместе с Windows.
- 🧹 **Clean Exit** — При отключении приложение автоматически завершает свои процессы Tor на сервере, не оставляя "мусора".

## 🚀 Как это работает?

1. **Direct Mode**: Использует стандартный динамический проброс портов SSH (`-D`).
2. **Tor Mode**: 
   - На сервере запускается изолированный процесс Tor, слушающий локальный порт.
   - Создается SSH-туннель (`-L`), соединяющий ваш компьютер с этим портом Tor.
   - Трафик выходит в интернет через выбранную в меню страну (`ExitNodes`).

## 📥 Установка

1. Скачайте последнюю версию из [Releases](https://github.com/USERNAME/REPO_NAME/releases)
2. Распакуйте `ssh_proxy.exe` в любую удобную папку
3. Запустите файл
4. Для автозапуска программу можно скопировать в shell:startup или сделать ссылку на нее туда
5. В браузере для выбора прокси лучше использовать расширения типа FoxyProxy

## 🛠️ Использование

1. **Setup**: Правой кнопкой по иконке в трее → **Settings**. Введите данные вашего сервера.
2. **Select Route**: В меню **Traffic Route** выберите "Direct" или желаемую страну.
3. **Connect**: Нажмите **Connect**. Индикатор в трее станет зеленым при успешном подключении.
4. **Browser Config**: Установите в браузере SOCKS5 прокси: `127.0.0.1:1080` (порт можно изменить в настройках).

### Параметры настройки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| User | SSH-пользователь (рекомендуется обычный пользователь) | `ubuntu` |
| Host | IP или домен вашего сервера | — |
| SSH Port | Порт SSH сервера | `22` |
| SOCKS Port | Локальный порт для ваших приложений | `1080` |
| Autostart | Автосоедиенение | `false` |

## 🏗️ Сборка из исходников

### Требования
- Go 1.25+
- Наличие `ssh` клиента в системе (Windows 10/11 имеет встроенный OpenSSH).
- Сервер на базе Debian/Ubuntu для автоматической установки Tor (опционально).

### Компиляция
```bash
go build -ldflags "-H=windowsgui -s -w" -o ssh_proxy.exe main.go
```

## ⚠️ Требования к серверу
Для корректной работы режима Tor:
- ОС: Debian, Ubuntu или аналоги с менеджером пакетов `apt`.
- Права: Пользователь должен иметь возможность выполнять `sudo apt install` (только для первой установки Tor) или Tor должен быть установлен заранее.
- На сервере не блокируются локальные порты (9060).
