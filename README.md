# SSH SOCKS Proxy

SSH SOCKS Proxy — это легковесное приложение для Windows, которое создает SOCKS5-прокси через SSH-туннель. Работает в системном трее, поддерживает автоматическое подключение и настройку через GUI.

## Возможности

- 🖥️ **GUI в системном трее** — управление из иконки в трее
- 🔐 **Автоматическая настройка SSH-ключей** — генерация и загрузка ключей на сервер
- 🚀 **Автостарт** — автоматическое подключение при запуске приложения
- ⚙️ **Настройки через GUI** — удобный интерфейс для настройки параметров
- 🎨 **Индикация статуса** — цветовая индикация состояния подключения

## Установка

1. Скачайте архив из [Releases](https://github.com/USERNAME/REPO_NAME/releases)
2. Распакуйте `ssh_proxy.exe` в любую папку
3. Запустите приложение

## Использование

1. **Настройка**: кликните правой кнопкой по иконке в трее → "Настроить"
2. **Подключение**: кликните правой кнопкой → "Подключить"
3. **SOCKS5 прокси**: используйте `localhost:1080` в настройках браузера или системы

### Параметры настройки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| Пользователь | SSH-пользователь на сервере | `ubuntu` |
| Хост | IP или домен сервера | — |
| SSH Порт | Порт SSH | `22` |
| SOCKS Порт | Локальный порт прокси | `1080` |
| Автостарт | Подключать при запуске | `false` |

## Сборка из исходников

### Требования

- Go 1.25+
- Windows (для сборки Windows-версии)
- 7z (для архивации)
- GitHub CLI (для публикации релизов)

### Локальная сборка

```bash
# Сборка без публикации
go build -ldflags "-H=windowsgui -s -w" -o ssh_proxy.exe main.go

# Сборка и публикация релиза
build.bat
```

### Публикация релиза

1. Измените версию в файле `VERSION`
2. Закоммитьте изменения
3. Запустите `build.bat` — скрипт создаст релиз на GitHub

Или создайте тег вручную:

```bash
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions автоматически соберет и опубликует релиз.
